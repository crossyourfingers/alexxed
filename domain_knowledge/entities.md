# Core Entities

- **User**: A registered participant (viewer or streamer).
- **Channel**: A chat or content stream space.
- **Message**: A chat message sent in a channel.
- **Reaction**: Emoji or like attached to a message.
- **Game**: A game available for voting/streaming.
- **Vote**: A user's upvote/downvote for a game.
