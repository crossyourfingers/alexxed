# Key Features

- **Real-time Chat**: Instant messaging in channels.
- **Game Voting**: Community votes on which games Alex should play next.
- **Emoji Reactions**: Users react to messages with emojis/likes.
- **Stream Schedule**: View upcoming streams and events.
- **Authentication**: Secure login and identity management.
